# IBM Plex (self-hosted)

Curated subset for SwimEdge / ISA portal. Source: Google Fonts download (IBM Plex Sans, IBM Plex Sans Hebrew, IBM Plex Mono).

Licensed under [SIL Open Font License 1.1](OFL.txt).

| Folder | Weights | Use |
|--------|---------|-----|
| `hebrew/` | 400, 500, 600, 700 | Hebrew UI copy (RTL) |
| `sans/` | 400, 500, 600, 700 | Latin UI fallback |
| `mono/` | 500, 600 | Swim times / technical LTR data only |

`@font-face` declarations: `frontend/src/styles/fonts.css`
